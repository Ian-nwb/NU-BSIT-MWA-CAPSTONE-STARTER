# Mobile — Flutter Client

The Flutter client. It consumes the same REST API as the web frontend (`backend/`), so all business logic lives in the backend — this app handles UI, state, and API calls only.

## Tech

- **Flutter** (Dart) — Android, iOS, and web from one codebase
- **`mobile/lib/firebase_options.dart`** — generated by `flutterfire configure` (only if your capstone uses Firebase)

## Getting Started

```bash
cd mobile
flutter pub get        # install dependencies
flutter doctor         # verify your setup
flutter run            # pick an Android emulator, iOS simulator, or browser
```

Useful variants:

```bash
flutter run -d chrome        # run as a web app (same build the Dockerfile serves)
flutter test                 # run unit/widget tests
flutter analyze              # static analysis
flutter build apk            # Android release build
flutter build appbundle      # Android Play Store build
flutter build ios            # iOS build (macOS only)
```

## Configuration

Create `mobile/.env` from the example:

```env
API_URL=http://localhost:5000/api
```

> Running on a **physical device**? `localhost` won't work — use your machine's LAN IP (e.g. `http://192.168.1.10:5000/api`) so the phone can reach the backend.

## Project Structure

```javascript
mobile/
├── android/            # Android platform code
├── ios/                # iOS platform code (macOS only)
├── integration_test/   # Flutter integration tests (runs with flutter test)
├── lib/
│   ├── api/            # API client layer (calls the Express backend)
│   ├── components/     # Reusable widgets
│   ├── pages/          # Screens
│   ├── hooks/          # Shared state/logic helpers
│   ├── context/        # App-wide state (auth, theme, etc.)
│   └── utils/          # Helpers
├── web/                # Web entry point (used by the Docker web build)
├── Dockerfile          # Flutter web build served by Nginx
└── .env.example
```

## Docker (web build only)

The Flutter **web** build can run in Docker:

```bash
cd infra
docker compose up -d --build        # includes the mobile web container on :8080
```

Android/iOS builds cannot run in Docker — use `flutter run` locally for those.

## Firebase (optional)

If your capstone uses Firebase (FCM push notifications, Auth, Firestore):

```bash
dart pub global activate flutterfire_cli
flutterfire configure        # generates lib/firebase_options.dart
```

See the root README's *Environment Variables → Firebase* section for the full setup.
